# RIM·CS — памятка для Claude (начни отсюда)

Бесплатное веб-приложение «Приложение Рима» (Telegram Mini App / Safari) для подготовки русского комментатора к матчам CS2 тир-1 (тир-2 не улучшать). Всё должно оставаться бесплатным.
Подробное устройство каждой функции — в `NOTES.md` (искать там по имени функции/слову, целиком не читать).

## Правила владельца

- Отвечать по-русски, коротко, без технических подробностей; иметь своё мнение, а не просто соглашаться.

- Ключи (PANDASCORE_TOKEN, GIGACHAT_KEY, GEMINI_KEY, ODDSPAPI_KEY) — только в GitHub Secrets, в чат не просить.
- Не обходить защиту сайтов. HLTV: ≤1 запроса / 2.5 с, только в полном сборе; 403 — пауза страницы 1/3/7 дн. (`hfail:`), рейтинг VRS `/valve-ranking/teams` — 1/2/4/6 ч (владелец: «чрезвычайно важна»); три 403 подряд — стоп; 429/503 — минута и один повтор.

- Нейросеть: сначала бесплатные модели Google (`GEM_CHAIN`), Сбер GigaChat (Freemium) — запасной; Groq/Mistral владельцу не нужны.
- Когда диалог длинный — обновить ЭТОТ файл (состояние, задачи, новые правила; коротко, заменять устаревшее), подробности — в NOTES.md; коммит в main с `[skip ci]`, владельцу одной строкой: «Обратись к CLAUDE.md, проект RIM·CS».
- Подпись коммитов — по system-reminder сессии.

## Где что
- `docs/index.html` — всё приложение (один файл; новый вид — блок `<style id="redesign">`). Данные — ветка `data` (raw.githubusercontent, `dfetch` с кэшем в памяти/localStorage/IndexedDB).
- `collector/collect.py` — сборщик (полный / `STATS_ONLY=1` / `NEWS_ONLY=1`), `collector/save_data.py` — слияние в ветку `data`, `collector/vrs_model.py` — расчёт VRS по программе Valve.
- Workflow: `collect.yml` (полный, каждый час + запасной cron с `gate`), `stats.yml`, `news.yml` (проход раз в 5 мин), `pages.yml`. Будильник — Cloudflare-воркер `tools/cloudflare-worker.js`.
- Запуск вручную: `gh api -X POST repos/vladrimskij-a11y/cs-prep/actions/workflows/<wf>.yml/dispatches -f ref=main` (`gh workflow run` не работает).
- Песочница внешних сайтов не видит — проверка источников через probe workflow; вёрстка — Playwright локально (данные из ветки data в /tmp).
- Публикация Pages: проверять в логе deploy «Reported success!», не зелёный значок.
