# CS RIM

Telegram Mini App для подготовки комментатора к матчам CS2 тир-1.

- **Список матчей** на неделю вперёд по дням, время по Москве. Матчи, которые ты ведёшь, отмечаются микрофоном.
- **Карточка матча**: личные встречи с датами и турнирами, статистика по картам, последние игры на каждой карте, форма команд.
- **Игроки**: составы, у каждого игрока счётчик свежих новостей.
- **Новости за 7 дней** про игроков и команды: Google News (рус. и англ.), HLTV, Cybersport.ru. Совпадения не по теме отсеиваются по правилам, английские заголовки переводятся на русский.

Источники: матчи и составы — PandaScore (бесплатный тариф), история, личные встречи и карты — bo3.gg.

## Как это работает

Отдельного сервера нет. Всё бесплатно и живёт на GitHub:

1. Каждые 3 часа GitHub Actions запускает `collector/collect.py`.
2. Скрипт собирает данные и сохраняет их в `docs/data/`.
3. GitHub Pages раздаёт `docs/` как сайт, а бот в Telegram открывает его как Mini App.

## Настройка

1. **Секрет PandaScore**: Settings → Secrets and variables → Actions → New repository secret. Имя `PANDASCORE_TOKEN`, значение — токен из дашборда PandaScore.
2. **Сайт**: Settings → Pages → Source: *Deploy from a branch*, Branch: `main`, папка `/docs` → Save. Через минуту появится адрес вида `https://<логин>.github.io/cs-prep/`.
3. **Первый запуск**: Actions → «Обновить данные» → Run workflow.
4. **Бот**: в @BotFather `/mybots` → твой бот → Bot Settings → Configure Mini App → Enable Mini App → вставь адрес из шага 2. Там же в Menu Button можно поставить этот адрес, чтобы кнопка «Матчи» была прямо в чате.

## Настройки сборщика

Меняются в начале `collector/collect.py`: уровни турниров (`TIERS`), глубина новостей (`NEWS_DAYS`), список RSS-лент (`RSS_FEEDS`). После любого изменения сборщика данные обновляются автоматически.
